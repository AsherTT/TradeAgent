# 方案 B 股票投研：后端复用与补充架构

更新：2026-10-09，Asia/Shanghai。用户确认以方案 B（Fiscal 式股票投研控制台）为主骨架，并要求整理股票研究的架构、进度与后续开发项。本文是 v1.1.1 的产品能力补充，不改写冻结基线，也不是已实现接口规格；状态和任务唯一维护在[开发计划](../01_项目总览/DEVELOPMENT_PLAN.md)。

## 结论与范围

P1–P9 提供可复用底座，尚不能直接满足完整股票投研产品。原蓝图已有 LONG_TERM 的 Fundamental/Valuation、历史 Thesis、Bull/Bear/Critic 等方向，但当前实现与真实资格不齐，估值、股本及同行比较也缺具体产品契约。继续在原架构扩展，不另建后端、不连接参考网站的私有服务。

主路径：选择具体证券 → 公司与财务 → 合格行情/估值/同行 → 提交有预算的研究 → 阅读报告并核验证据 → 跟踪论点与失效条件。首版市场范围由已接入证券和已验证来源确定；现有 SEC 美股年度切片不能推导 A 股、港股或全市场覆盖。实时分钟行情、交易下单、真实持仓/收益归因、券商同步及全市场筛选仍不进入首版。

## P1–P9 实现核对

## 服务与数据流

继续复用 Next 同源 BFF → FastAPI 账户应用层 → 领域查询/计算 → SQLAlchemy/PostgreSQL；采集和模型走已有来源适配器、Redis/Celery 与有界研究图。浏览器不直接查询数据供应商、内部研究令牌端点或数据库。

需要补的领域职责为证券/股本、财务序列、行情研究读取、估值、同行比较和研究能力准入。模块名、迁移、URI/DTO 和预算在各增量 spec 冻结；这里不宣称新端点已可调用。事实与计算结果优先复用已有 Evidence/RAG、来源适配与质量规则，新增分表/存储前验证必要性。

### 证券与公司关系、股本（BE-12）

- 永久证券 ID 保持；补发行人/公司、证券类别、上市地、交易币种与时间有效关系。换 ticker、换交易所或 ADR 不视作无条件同一股票，ADR 转换和多股类须明确。
- 股本保存时点、实际流通/总在外股数及来源；每股指标区分基本/稀释、期间加权平均与时点在外股数。加权平均 EPS 分母不直接当作市值分母。
- 价格、股数、财务及公司行动必须属于可兼容身份、币种、调整方式与时间口径；拆股前后不得重复调整。映射或口径未知则结果不可用，不用名称猜测。
- 现有目录仍是有界本地目录；已退市对象的实时操作保持现有拒绝规则，历史读取若开放需独立契约和资格。

### 多期财务与确定性分析（BE-02/03）

补三张报表所需概念、年度/季度/TTM、申报与修订版本、分部/KPI。保留原始及标准化映射、币种/单位、期间、可用时间和原文定位。增长、利润质量、现金流、债务等由后端按版本化公式计算，缺值/口径不兼容不填 0。当前已知年度四概念及两个比例保留为受限能力，不覆盖新增分析要求。

### 行情研究与资格（BE-13、DATA-01/02）

- 有界读取价格/历史窗口/确定性技术指标，展示交易时间、观察/可用时间、币种、数据延迟、来源/质量版本与调整方式；不默认许诺实时数据。
- 报价读取、调整后技术分析、严格历史回测的用途/准入分别记录，沿用各用途现有质量门槛；任何用途的成功不提升其他用途资格，UNVERIFIED 采集诊断不作为合格研究证据。
- 估值所需行情与公司行动/股本对齐在 R2 前置验证；历史证券池、完整调整窗口及严格回测继续 R5，不能让 R2 估值依赖一个尚未实现的 R5 产品页面。
- 不修改 Analysis Timestamp 以掩盖晚到数据，不绕过 action completeness 或用来源连通冒充质量认证。

### 基础估值与同行（BE-14/15）

- 先定义可用数据支持的市值、企业价值及估值倍数；正式公式/适用范围由 spec 冻结。每个结果附公式版本、输入事实/价格/股本 IDs、期间/时点、单位、来源及缺项原因。
- 同期/可比口径不足、价格过期、币种缺失、亏损或分母不适用时区分状态；净债务/企业价值组成项缺失不按 0，行业不适用不硬套通用指标。历史倍数必须用当时可知输入，不能把当前股本乘所有历史价格。
- 同行首版采用用户明确选定的有界证券集合（数量上限在 spec 冻结），校验截止时间、单位/币种、报表模板与可比性；不可比的格子保留原因，不以空值排序出假优劣，不扩成全市场筛选器。
- 估值是证据与假设下的计算结果，不自动生成买卖指令或承诺目标价。源站评分/共识/雪花图不得映射成自有研究置信度。

### 研究、报告与论点（BE-04～08、BE-16）

- 将业务/行业、财务、行情/估值、事件、风险、支持/反证定义为可校验能力；按问题与 horizon 明确必需/可选项、数据截止时间、来源准入及保留缺口。SHORT_SWING/LONG_TERM 的原路由约束保留，不静默修改用户研究目标。
- 新能力有具体采集/计算结果与来源 ID 后才能满足 Gap Judge；不得只扩白名单或沿用旧 sufficient 状态宣布完整股票研究。图状态、报告、QualityAssessment、账户 options/DTO 及前端缺口显示需一并验收，老快照也需诚实显示其能力范围。
- 独立 Critic 的输入/输出、预算与检查点独立定义；逐条事实、计算、假设、模型解释分层。引用存在不证明解释正确，非空业务/催化剂输出与完整综合需各自验证。
- 本人历史论点按 instrument/account/截止时间检索；上传材料不提升信任，估值情景不直接写为冻结预测。Forecast 的完整综合、方向/概率匹配、时间及不可变规则保留。
- 来源失败只能在预算、PIT 与原要求内重规划；缺口持续则保留可读部分报告。预算耗尽、取消及未知外部结果都保持现有持久语义。

### 可选情景估值与结果评估（BE-17、BE-09～11）

DCF/反向 DCF、敏感性及情景比较单列为后续可选工具，默认不启用；SHORT_SWING 的 DCF OFF 不变。只有数据、单位、假设/折现口径、敏感性与失败状态规格齐备后实施，不因方案 B 被接受便展示虚构目标价；不作为基础股票研究首版的强制上线条件。

Outcome 继续要求当时冻结预测和以后合格价格/基准观察，记录足够样本与成熟度。账户工具和评估查询先验归属，不把全局 cohort、fixture 收益或未到期预测包装为自己的历史表现。真实交易、真实组合及历史 LLM 补造信号均保持原限制。

## 交付顺序与验收

1. R1：方案 B 的实际界面/状态采样、证券上下文与已有任务/报告映射；当前功能骨架不能因选型变成已还原。
2. R2：多期财务 → 证券/股本及用途合格行情 → 确定性财务/基础估值 → 有界同行比较；采集受限时先做适配器接口与离线金例，真实资格另记。
3. R3：本人授权材料/保存片段/版本/引用定位与阅读联动。
4. R4：业务/行业/事件/风险能力及完整股票研究准入、Critic、论点 API/记忆回流；按供应商和预算取得真实受限执行资格。
5. R5：历史来源、成熟 Outcome、账户策略/评估及可选情景工具；R6 端到端股票研究、双语/响应式/无障碍及账户权限验收。

每项区分“领域代码/离线验证”“账户 API/真实 PG-BFF 联调”“真实数据/模型资格”“产品验收”。典型验收覆盖拆股/ADR/股类、股数口径、迟到/修订/PIT、币种与期间不一致、零/负/缺分母、未知质量、同行不可比、他人/历史未归属对象、取消/预算与重放、老报告能力范围和不满足冻结资格的拒绝。研究结论和指标必须能追到持久化输入；不要求模型保证投资结论正确或预测收益。

本次仅文档核对与任务登记，无运行代码/迁移/API变更、无模型/worker启用、无新测试或真实资格声明。P10 仍 R1，R2 未启动；P5 完整研究与真实来源资格未完成。对应任务与状态见[正式待办](../01_项目总览/DEVELOPMENT_PLAN.md)，当前进展见[进度入口](../01_项目总览/DEVELOPMENT_PROGRESS_20261008.md)。
