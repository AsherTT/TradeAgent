## 自有后端契约

新增只读 `GET /workspace/portal` 与 `GET /workspace/companies/{instrument_id}`。复用服务器账户会话、公司/关注、精确账户研究提交/查询/取消/报告，不开放内部接口。公司目录为本地记录，不承诺全市场资格。

- 两个新接口均未登录401、响应no-store；未知/已退市公司404，非法ID422。新API不写业务状态，不调用外部来源或模型。
- 门户返回分页关注公司、分页本人最近研究、最多3项本人活动研究和明确的本地目录范围。分页参数 `limit` 默认12、范围1～20；`watchlist_offset` / `research_offset` 默认0、范围0～10000。列表总数来自后端，固定时间与ID排序，不能把当前页长度当总数。
- 公司详情返回公司身份、本人is_followed、分页本人该公司研究及本地目录范围；使用 `limit` / `research_offset`。本人研究同时按user_id和instrument_id过滤，历史未归属研究不可见。
- 每个分页对象为items、total、offset、limit；研究条目复用安全摘要，不返回state_json、内部runtime_metadata、执行凭据或他人内容。活动判断使用实际pending/running；完成/预算/完整性仍由现有后端契约判断。
- BFF新增精确GET白名单和严格UUID路径，只转发本spec声明的查询参数；权限仍在后端逐请求验证，保持原有写入Origin保护、超时与no-store。
- 研究页面的company查询参数只用于预选已有目录公司，未知/超出当前目录的对象明确说明。不得改变预算、提交模式或Analysis Timestamp，不自动提交任务。
