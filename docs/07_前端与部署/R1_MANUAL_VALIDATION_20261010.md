## 本轮 Fiscal 效果（无需登录）

1. 打开搜索组件预览，初始输入为 `HOOD pages`，清空次数为0。
2. 鼠标移到 `Clear Search`，文字淡化；点击后输入为空、清空按钮消失、次数为1。
3. 点击“重置示例”。在输入框按 Tab 移到清空按钮，出现焦点框；按 Enter 后仅清空一次。
4. 再重置，同样按 Tab 到清空按钮，按空格后仅清空一次。重置会把清空次数恢复0。
5. 输入自定义文字，切 EN/中文，输入和清空次数保持；刷新后保留语言偏好，示例状态重新初始化。
6. 用浏览器开发者工具响应式模式分别设为1440、768、390宽度。页面无横向溢出；清空按钮均为100×30；移动端底部英文搜索提示自然换行为三行。
7. 无结果文字和搜索提示明确为静态来源样本，始终可看。提示中的结果导航并未在此开发预览实现；不能将本页当作完整搜索弹窗。

来源子控件保留英文和来源字体，便于核对原样；外围说明和导航有中英切换。完整来源页仍待采样/实现与接入后验收。

## 正式功能骨架

1. 打开 `/app`；已有会话直接进入，否则用自己的已有账号登录，无账号可从注册入口自行建立。
2. 在“公司目录”的“搜索公司或股票代码”输入已接入代码，例如当前本地目录的 `KLAC`；稍等查询完成，打开“查看公司”。本地目录包含资格验证样本，不是全市场或实时证券目录。
3. 查看公司身份和本人研究记录。关注/取消关注会修改自己的本地账户数据，可按需测试后恢复。
4. 查看已有研究任务及报告入口；公司页进入研究页可检查公司预选、预算和准入说明。
5. 当前模型开关关闭，worker/beat未运行。已有等待执行任务不会自动完成；本轮界面验收无需提交新研究，也不能据此验收真实研究闭环。
