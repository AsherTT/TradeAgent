## 方案2最终定义与适用范围

目标：在原P1～P9底座上完成P10研究平台，前端逐页/逐功能区开发，当前区块需要的后端能力随该区块补齐。复刻质量不降低，开发范围不随原站导航自动增长。视觉主骨架继续使用已选Fiscal方案B；这里的“执行方案2”与此前视觉A/B/C选型是不同维度。

核心路径：本地目录选证券 → 公司概览/关注 → 有来源的行情、财务、基础估值/有界同行 → 有预算的研究任务 → 报告/引用及已保存原文核验 → 论点/反证与研究变化。

首版证券范围为本地目录中身份及来源已验证的证券，先以一个可观察的代表证券验收，再有界扩展；SEC适配能力不推导全球/A股/港股覆盖。搜索按实际目录接线，来源lab保留四分类与上市样本；未建产品目录的基金、投资者、多上市映射不冒充可用能力。

### 两个完成点

1. **R1现有网站第一版完成：** 搜索及Simply选定来源区块收尾，整个现有/app的门户、公司、研究列表/提交/状态/报告与账户入口完成重构，并接已有自有接口。来源受限完整分析师、整商业公司报告、全球搜索、47页内部搜索和自定义滚动条全产品状态不再是此版本前置；本轮选定控件/布局/实际状态仍须明确规格及对照。基础报告可读不等于完整AI研究已具备资格。
2. **P10研究平台完成：** R1～R6已承诺模块按各自冻结规格完成前端、必要后端、接线及质量/权限验收；至少一条有预算的代表研究链在取得独立运行准入后以真实来源验证，报告能核验引用/范围/缺口。已承诺功能只有样本或接口空壳时不能标完整P10；未启用真实执行时保留“功能已实现/真实运行待准入”的分层状态。P10完成不等于已经公网部署或证明投资收益。

## 方案1：现有能力先成站

目标：先交付完整的现有产品网站，让“选公司 → 发起研究 → 看状态 → 读已有报告”在统一研究空间中可操作。

实施顺序：

1. 收尾已选搜索弹窗和Simply来源区域：补短窗口滚动、清空/关闭/焦点等已选控件状态；受限完整分析师与整公司商业报告不成为本版本前置。
2. 重构/app应用壳和门户：公司搜索、关注、最近研究、活动任务、分页与研究变化接现有接口。
3. 重构/app/companies/[instrumentId]：公司身份、关注、已有本人研究及发起研究；采用Fiscal布局，按自有对象绑定。上市地点样本留在来源对照页，未经身份映射不伪装产品证券目录。
4. 重构研究列表/提交/状态：已有条件选择、预算、取消、失败/会话处理。
5. 重构报告与账户入口：已有报告章节、引用元数据、来源/时间；原文未保存时不显示伪造全文。
6. 完成首版中英/三尺寸、导航/刷新/返回、空/错误/重试和权限验收。

后端：仅补上述交付所需的安全展示DTO或确实缺失的映射，不新建行情、共识、持股服务。公司来源区显示TradeAgent实际可查的证据/来源/更新时间，未知项明确不可用，不能照搬S&P供数说明为自有能力。

本版不显示样本价格曲线作为真实行情，也不许诺15分钟延迟。R2～R5保留为后续，先交付现有网站。现有任务接口可验证不等于已开启模型生成新报告。

验收：搜索本地目录中的真实证券，进入其稳定公司地址；关注、研究入口、任务/报告导航均到本人对象，刷新/返回正确。已有报告可读，无报告可解释；未增加业务的数据页不能计为完成。

选择后第一块交付：搜索/公司来源已选区块收尾及验收，再交付/app应用壳与门户。

## 方案3：完整公司终端

目标：把图中的Fiscal公司页及Simply完整公司分析章节作为长期产品范围，除原有研究链外，增加明确的数据模块；每个页签分别开发，不一次开工全部模块。

实施顺序：

1. 冻结首版公司终端页签/章节映射、来源可访问范围、已有/新增接口和数据供应商方案；商业API可用范围、价格与展示许可尚待确认，不自动购买。
2. 先完成现有网站与公司终端外框，接公司/关注/研究/账户；来源对照页可展示采集样本，但不计数据功能完成。
3. 补行情与历史图、多期财务及分部/KPI、股本/估值/同行，并按不同期间与数据用途验收。
4. 补公司材料/申报文件目录与阅读；完整IR音视频是否纳入另定范围，不能随页签自动承诺。
5. 单独建设Estimates分析师共识、News新闻/事件、Ownership股东与内部人交易的采集、持久化、查询及质量/时点契约。AI预测不是分析师共识，股本不是持股分布。
6. 为Simply拟保留的估值、增长、财务健康、分红、管理/持股章节逐项提供真实输入和自有计算；不直接复制原站结论、评分或供应商身份。
7. 完成研究/证据/论点与工具接入，各已承诺页签逐项验收，再做整体验收。

后端：除了R2～R5既有任务，还须新增共识、新闻、持股等正式任务，先更新契约、架构和数据依赖。继续复用原后端，不另起技术栈。

来源权限影响：受限章节可能缺完整DOM/交互样本，因此其全状态1:1验收可能延后；数据源不成立时不能把该页签记完成。其他已具备样本和接口的页面可以继续交付。不是购买网页会员就自动获得应用的数据API授权。

验收：首版承诺的每个页签有真实数据、来源/时间/缺项状态和可操作接口；交付期间以模块已完成清单说明，不承诺一轮完成完整终端。实时交易、券商同步、社交、收费系统和全市场筛选仍在本方案之外。

选择后第一块交付：先交付终端功能/接口/数据来源映射与新增任务清单，明确新增工作，再实施现有产品外框与接线。数据模块总体工作量最高。
