## 搜索
1. 打开搜索地址，默认直接显示弹窗。需要原样对照时点右上角关闭，切EN，再点Open search。
2. 在All、Companies、ETFs & Funds、Investors间切换；滚动看真实logo、旗帜和结果。分别在Companies输入AAPL、在ETFs输入QQQ，得到对应参考样本。
3. 用上下键切选择，Enter确认；或点击某一行。弹窗关闭后显示已选参考结果；View source page才会打开原网站，不修改自有证券记录。
4. 输入zzzz-no-reference，看到无结果；清空输入恢复该分类的样本。Escape或关闭按钮退出。
5. 输入AAPL，关闭→切中文/英文→重开，文字与分类保留。刷新保留语言偏好，预览选择/输入重新初始化。
6. 开发者工具分别检查1440×1000、768×1000、390×1000：桌面居中1000宽，平板/手机全屏，手机Investors标签自然换到第二行。空query的Tab保持输入焦点是已采原站状态；Shift+Tab能返回关闭按钮。

当前输入只筛选30条采集参考样本。全球证券搜索、HOOD pages等47页模式、上市地点展开及完整公司页尚未接入；原站提示保留用于比对，不代表这些功能已完成。

## 公司来源
1. 切EN与来源逐项比对：桌面左侧身份/章节目录、右侧Company Analysis and Financial Data Status及四个连续来源区域。
2. 向下看数据来源表、分析模型/行业说明、公开分析师三行；窄屏侧栏隐藏，表格可横向滚动，整页无横向溢出。
3. 切中文查看译文。目录及正文来源链接打开真实来源网站；市值/更新时间为采集参考值，非TradeAgent实时数据。
