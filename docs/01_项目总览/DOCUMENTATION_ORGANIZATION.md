## 目录职责

1. 项目总览：当前检查点、状态、进度与历史核验。
2. 架构与契约：整体架构、领域数据规则、模型网关和架构决策。
3. 研究与分析：研究编排、财务、催化剂、综合归因和报告规范。
4. 数据源与检索：外部来源、材料审计、安全RAG与机器可读提供商资格。
5. 记忆评估与策略：论点/预测、回放/到期评估、量化、回测和风控规范。
6. 验证与审查：阶段验收、来源资格验证、审查与修复记录，按主题再分子目录。
7. 前端与部署：前端策略和后续部署材料；目前 P10 暂停、P11 未实施。

总入口为 [docs 导航](../README.md)。每个目录有中文阅读标题与文件清单；
文件名保留，以便搜索和追踪历史。既有历史材料不删除、不合并或改写资格结论。
[路径对照表](DOCUMENTATION_PATHS.md)保留旧交接与Git历史的定位能力。
