# Bootstrap fonts

These files are the same Geist and Geist Mono Latin variable fonts emitted by
this template's successful Next.js 16.3.5 production build using next/font/google.
They are loaded with next/font/local to prevent Google download timeouts in dev.

- GeistLatin.woff2: original build media caa3a2e1cccd8315-s.p.0wgildi0cnwt9.woff2.
- GeistMonoLatin.woff2: original build media 797e433ab948586e-s.p.0r6juujl39pe6.woff2.
- Font weight range: 100-900; style: normal; selected character coverage: Latin.
- Font project: https://github.com/vercel/geist-font
- License: SIL Open Font License 1.1, included in OFL-Geist.txt.
- Included license retrieved from https://raw.githubusercontent.com/google/fonts/main/ofl/geist/OFL.txt.

These are only the untouched template's bootstrap fonts. During source-site
cloning, use the source's actually observed typography and appropriately licensed
font assets, as required by the clone-website skill.
