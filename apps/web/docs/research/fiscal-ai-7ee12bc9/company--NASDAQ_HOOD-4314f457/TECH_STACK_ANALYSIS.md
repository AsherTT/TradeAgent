# 来源技术观察

DOM/CSSOM 出现 `mantine-AppShell-*`、`mantine-ScrollArea-*`、`mantine-Tabs-*` 和 Tailwind 风格响应式类；资源和图表控件出现 Highcharts。计算字体 Plus Jakarta Sans，来源字体 CSS 还声明 DM Mono / Space Grotesk。以上只证明公开观察，不证明服务端、供应链或账户契约。

本地仍按 Next.js 16 / React 19 / strict TypeScript / Tailwind v4 标准实现，不直接注入来源脚本、整站 CSS 或第三方图表内部 DOM。图表技术和操作映射待全状态规格确定，当前未安装新包。
