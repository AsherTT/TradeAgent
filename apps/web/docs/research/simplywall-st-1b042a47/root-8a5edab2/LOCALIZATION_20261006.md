# 首页中文 / 英文扩展 — 2026-10-06

用户明确要求页面增加中文和英文。这是独立来源首页原型上的语言扩展，当前本地地址仍为 http://127.0.0.1:3107/ 。实现提交：85baeb2；审查固定点：ed5501fb3569976b345df62917234d2bc5cb540f。

## 已完成

- 桌面导航和手机展开菜单提供 中文 / EN 按钮；默认简体中文，选择保存一年，刷新保留。非法存储值回退中文。
- 13 个页面区域，包括导航、正文、按钮、研究选项、用户评价、页脚；254 个来源文字/图片说明均有非空译文。字典另含语言组和页面元信息，共257条。
- 服务端首次渲染读取语言 cookie，HTML lang、标题和内容一致。客户端实时切换文案、图片说明、菜单名称、lang和标题；研究组件不重建。
- 保留原英文文字、图片、视频和外部链接。图片与视频内的英文保留；外部页面不受本地语言选择控制。
- 992–1199px 隐藏临时导航搜索，并允许正文股票搜索列收缩，解决实测21px的横向溢出。其余源站结构保留。
- 本地消息表和语法树转换脚本，无新增依赖或在线翻译服务。现有13区域生成流程自动应用语言扩展。
