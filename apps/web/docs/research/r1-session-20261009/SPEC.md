## 本轮实现边界

1. 公司、研究列表/提交、任务/报告的会话失效统一遵循既有门户约定：先标记会话失效，停止计时并中止在途读取，再清空私有状态，转到登录。
2. 即使请求传输忽略 AbortSignal，迟到的成功/失败响应仍不得恢复私有内容、重新轮询或跳转到旧账户任务；401 后刷新/重试不能重启失效会话。
3. 研究提交 401 清理问题文本、对象选择与幂等请求身份；取消 401 同时清理任务和报告。正常提交、关注、取消、分页与有界轮询保持。
4. 应用导航“数据说明”进入 /app#data-scope，目标为自有目录/账户/能力范围说明。保留完整来源首页和旧联调稿。
5. 不改后端契约、数据库或来源权限，不启用 worker/模型，不操作用户已有关注和研究。
